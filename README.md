# MuQwiz

Веб-приложение для подготовки к музыкальным викторинам.

## Структура проекта

- `index.html`, `prepare.html`, `quiz.html`, `results.html`, `settings.html`, `account.html`, `reset-password.html` — страницы приложения.
- `css/` — стили.
- `js/` — основной клиентский код приложения.
- `account.js` — авторизация и облачная синхронизация Supabase.
- `assets/icons/` — favicon, иконки приложения и Apple touch icon.
- `manifest.json` — PWA-манифест (оставлен в корне, чтобы не менять область действия приложения).
- `src/`, `dist/`, `webpack.config.js`, `package.json` — исходники и настройки сборки.
- `ACCOUNT_SETUP_RU.md` — заметки по настройке аккаунтов.

## Публикация

Проект рассчитан на статическую публикацию (в том числе GitHub Pages). Сохраняйте относительные пути к файлам при переносе страниц и ресурсов.
