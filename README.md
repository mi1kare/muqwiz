# MuQwiz

Веб-приложение для подготовки к музыкальным викторинам.

## Структура проекта

- `index.html`, `prepare.html`, `quiz.html`, `results.html`, `settings.html`, `account.html`, `reset-password.html` — страницы приложения.
- `css/` — стили.
- `js/` — основной клиентский код приложения.
- `account.js` — авторизация и облачная синхронизация Supabase.
- `assets/icons/` — favicon, иконки приложения и Apple touch icon.
- `manifest.json` — PWA-манифест (оставлен в корне, чтобы не менять область действия приложения).
- `src/`, `dist/`, `webpack.config.js`, `package.json` — исходники и настройки сборки.
- `ACCOUNT_SETUP_RU.md` — заметки по настройке аккаунтов.

## Публикация

Проект рассчитан на статическую публикацию (в том числе GitHub Pages). Сохраняйте относительные пути к файлам при переносе страниц и ресурсов.

## Облачные викторины и права автора

Перед публикацией обновления с владением викторинами один раз выполни SQL из
`supabase/migrations/202611150001_quiz_ownership.sql` в Supabase → SQL Editor.

- Гости могут создавать и редактировать викторины только локально.
- Пользователь с аккаунтом выбирает при создании: сохранить на устройстве или опубликовать в облаке.
- Облачную общую версию может менять только аккаунт, указанный в `owner_id`.
- Остальные пользователи могут редактировать локальную копию; исходная общая версия не меняется.
- Локальные копии не отправляются в синхронизацию аккаунта и остаются на этом устройстве.
- Старые облачные записи, созданные до добавления `owner_id`, остаются доступными по ссылке, но их нельзя редактировать в облаке, пока владелец не будет назначен вручную.
